# Yellow Flowers

Sitio estático de un ramo de rosas amarillas neón que se forma progresivamente.

La rosa fotorrealista utilizada por el sitio está en `assets/yellow-rose-neon.png`.

- Abre `index.html` para la página principal.
- La página privada es `private.html`; su propia pantalla de acceso VIP usa la contraseña de demostración `rosasvip`.

La protección usa `sessionStorage`, por lo que es solo una experiencia visual de frontend: no protege contenido sensible de forma real.
